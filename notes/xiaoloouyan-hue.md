**Ai Agent economy  元年 调查**

### **NBER 权威学术综述：《An Economy of AI Agents》**

📄 _Gillian K. Hadfield & Andrew Koh, NBER (2025)_

这是一篇由 **国家经济研究局（NBER）** 发布的章节草稿，讨论了 AI 智能体如何在未来十年内与人类协同或竞争，并对经济机构、市场和组织结构提出重要开放性问题。具有强经济学理论基础、适合从宏观/产业经济角度理解 “AI Agents 作为经济参与者” 的影响。 

### **权威论文：《The Agentic Economy》**

📄 _David M. Rothschild et al. (2025), arXiv_

这篇学术论文提出 “Agentic Economy” 概念，分析了生成式 AI 和自主 Agent 如何通过程序化交互重构消费者与企业之间的市场关系，以及这种变化如何改变交易模式、市场组织和潜在经济结构。理论扎实，对理解 Agent 在市场中的角色尤其关键。 

### **权威论文：《Ten Principles of AI Agent Economics》**

📄 _Ke Yang & ChengXiang Zhai (2025), arXiv_

该论文结合经济学、决策理论与伦理学，系统提出 **AI 智能体经济的十条原则**，包括 agent 决策机制、对劳动市场的影响、伦理与监管框架等。这是一篇适合从经济理论根基去理解 agent 经济的文章。 

### **世界经济论坛深度分析：《Trust is the new currency in the AI agent economy》**

🌐 _World Economic Forum (2025)_

来自世界经济论坛的讨论性文章，从 **信任与社会接受度** 的角度切入，强调 AI Agent 经济不仅是技术或市场问题，而是深刻改变组织、责任和社会信任架构的经济现象。适合理解 agent 经济在人类社会制度层面的必然挑战。 

### **行业视角报道：《AI Agents Are Creating Value Across Industries》**

💡 _Forbes (2025)_

这篇 Forbes 深度商业分析文章遍访多个行业（客服、医疗、教育等），具体说明 AI 智能体如何为企业创造经济价值，并提出行业领导者在利用 agent 经济时的五大战略要点，是实战案例 + 商业洞察性文章。

可信的协议

就如历史上反复出现过的场景那样，技术的小精灵似乎又一次从瓶子中被释放出来了。一个（或一群）身份和动机都无人知晓的人，在历史中的一个不确定的时刻里召唤了这只小精灵。现在，如果我们能很好地利用它，这个小精灵或许能为我们所用，带来另一场变革，并有可能革新经济格局和人类社会各种事务的旧秩序。

让我们来解释一下吧。

互联网前40年的发展历史给我们带来了电子邮件、万维网、网络公司、社交媒体、移动网络、大数据、云计算以及物联网的早期生态。它极大地降低了搜索、协作和交换信息的成本。它降低了以下领域的准入门槛：新媒体、娱乐业、新式的零售业、新式的工作组织架构以及前所未有的数字化商业模式。通过传感器技术，互联网将智能整合到我们的钱包、衣物、汽车、建筑、城市甚至是我们的身体上。互联网已经完全渗透了我们所处的环境，在不久的将来，我们就不需要像今天这样“登陆”到互联网上，而是会通过无处不在的（互联网）技术去运营我们的业务及管理我们的生活（持续的在线生活）。

可以这么说，互联网让很多积极的改变成为可能——对那些有着接入互联网条件的人而言更是如此。不过，对商业和经济活动来说，互联网还是存在着很大限制的。《纽约客》在1993年刊登过漫画家彼得•施泰纳的一幅漫画，上面写着“在互联网上，没有人知道你是一条狗”，估计在今天，这句话还是非常贴切的。在互联网上，若没有第三方机构—如银行或政府提供的校验信息，我们依然无法在彼此之间确认对方的身份，也无法在彼此间建立经济往来活动所需的信任关系。问题就出在这里——这些中间机构恰恰利用了我们对中介的需求，为了商业目的和国家安全等理由去收集我们的数据和侵犯我们的隐私。互联网技术改善了信息交换的效率，但即使是这样，这些中间机构所产生的额外成本依然让全球范围内25亿的人群难以负担各种金融服务。互联网曾经给很多人带来了一个期望——建立一个由点对点协议驱动的新世界，但其带来的经济和政治效益已经被证明是不对称的，权力和财富还是流向那些已经有权力和财富的人，即使他们已经没有再积极地努力做出贡献。资本们赚取新财富的速度，比大多数人都快。

相对于技术对隐私所带来的侵害，它所创造的繁荣程度并不能让人感到满意。不过，在这个数字化的时代，无论是好的还是坏的事情，技术已经处于一切事物的中心了。技术让人类更尊重和维护彼此的权利；同样地，技术让人类能够有更多的新方式去侵害彼此的权利。在线通讯以及在线商业的爆发式增长，让黑客们有更多的机会进行网络上的犯罪活动。摩尔定律预测了运算能力每年的翻倍式增长，而这也让诈骗活动和盗窃活动的活跃程度翻倍了，这个现象可用“摩尔的不法之徒定律” 来描述。至于垃圾信息传播者、身份盗窃者、在网上“钓鱼”的罪犯、间谍、僵尸网络入侵者（被植入恶意软件的机器组成的网络）、黑客、网络恶霸及数据敲诈者（那些用勒索软件去控制他人数据以牟利的人），这些人给互联网带来的影响也非常大。以上提到的仅仅是冰山一角。

寻找可信的协议早在1981年，一些发明家们就曾经尝试用密码学去解决互联网的隐私性、安全性和包容性的问题。由于第三方机构的存在，无论这些发明家们如何尝试重新设计互联网的基础流程，还是无法完全解决这些问题。在互联网上，用信用卡进行支付是不安全的——这是因为用户需要向第三方透露很多个人数据。另外，对小额支付而言，这个过程也会产生不菲的手续费。

这门课程是 JavaScript 版本，此前作者已经发布过 Python 版本，并取得了超过 200 万观看量，是目前全球观看量最高的智能合约教学内容之一。基于前一版课程的反馈与经验，这一版课程在结构、节奏和工具链上都进行了优化。课程面向所有人开放，不要求你有区块链背景，甚至不强制要求你有编程经验。如果你对 JavaScript 或任何面向对象编程语言有基础会更容易上手，但即使完全零基础，也可以通过课程逐步进入状态。

Patrick Collins 在开篇反复强调，这门课既适合想成为区块链/智能合约开发者的人，也适合并不打算写代码、但希望真正理解区块链与 Web3 运作逻辑的人。课程的前半部分会系统讲解区块链与智能合约的基本原理，这部分内容对产品、研究、治理、投资、DAO、Web3 文化等角色同样重要。

他将这门课形容为“掉进兔子洞的入口”，是一份高度浓缩、充满个人经验的知识输出项目。他非常明确地指出，Solidity 与智能合约开发者在当下市场中需求极高，平均薪资水平在 14.5 万美元左右，这既是技术变革带来的机会，也是一个结构性的经济机会。但比“赚钱”更重要的是，这项技术有潜力重塑我们与世界互动的方式，而学习者有机会成为这一变革的早期参与者。

课程将覆盖 DeFi、NFT、DAO、ERC20 代币、可升级智能合约等核心领域，目标是让学习者理解并具备构建去中心化金融协议、NFT 项目、DAO 组织等复杂系统的能力。这些系统的共同点在于，它们不依赖中心化中介，而是通过智能合约来执行规则。

Patrick 在课程中反复强调一个核心价值：构建去中心化应用，本质上是在构建一个更可问责、更透明、更高效、更具金融自由度的世界。这是一种将哲学与技术结合的新型社会系统，而智能合约正是这一系统的基础设施。

在学习方法上，他非常强调“跟着做”。课程配套了一个 GitHub 仓库，里面包含完整代码示例、时间戳、更新说明以及讨论区。这个仓库被他称为“学习圣经”，学习过程中应始终保持打开状态。区块链技术变化极快，文档和工具可能随时更新，因此当遇到问题时，第一步永远是查看 GitHub 仓库中的更新记录。如果仍有疑问，可以通过 Discussions、Issues 与其他学习者互动。

他还特别提醒，不要试图一口气学完全部内容。大脑在间歇式学习中记忆效果最好，建议每 25–30 分钟休息一次，每两小时进行一次较长的休息，并在进入新章节前回顾上一节的内容。同时，课程并不要求线性完成，你可以根据自己的目标选择性学习，比如跳过全栈部分、直接进入高级主题等。

在“学习成为区块链工程师”这件事上，Patrick 认为社区能力和工具熟练度与写代码本身同样重要。学会如何提问、如何在 GitHub、Stack Overflow、Ethereum Stack Exchange、Discord、Reddit、Twitter 等平台中参与讨论，是成为一名成熟 Web3 工程师的必经之路。他也强烈推荐参与 Hackathon，如 Chainlink Hackathon、ETHGlobal、Devfolio 等，这是学习、实践和建立人脉的最佳场所。

在正式进入编码之前，课程从区块链基础开始。区块链技术最早被比特币带入公众视野。比特币白皮书由中本聪提出，其核心目标是实现点对点的去中心化交易系统。由于其稀缺性和去中心化特征，比特币常被称为“数字黄金”，是一种价值存储工具。

随后，以太坊在此基础上进一步扩展了区块链的能力。Vitalik Buterin 提出了以太坊白皮书，并在 2015 年正式发布该项目。以太坊的关键创新在于引入了“智能合约”，使区块链不仅能转移价值，还能执行去中心化协议、组织和规则。虽然比特币也存在某种形式的智能合约，但它们是刻意设计为图灵不完备的，以保证系统安全与简洁；而以太坊则选择了图灵完备的智能合约平台定位。

智能合约这一概念最早可以追溯到 1994 年 Nick Szabo 的提出。智能合约可以理解为：在无需第三方的情况下，由代码自动执行的一组协议规则。与传统合同不同，它不是由人或机构来执行，而是由区块链网络自动、确定性地执行。

但智能合约也存在一个核心问题：区块链本身无法直接获取现实世界的数据。这被称为“预言机问题”。区块链是一个封闭且确定性的系统，而现实世界是开放且不确定的。为了解决这个问题，需要引入预言机（Oracle），即为区块链提供链下数据或计算能力的系统。

如果只依赖单一数据源或中心化预言机，就会重新引入信任风险。因此，真正可用的是“去中心化预言机网络”。Chainlink 正是在这一背景下诞生的，它通过去中心化节点网络，为智能合约提供可靠的数据输入、随机数、自动化执行等能力。结合链上逻辑与链下数据与计算，形成所谓的“混合智能合约（Hybrid Smart Contracts）”。

目前绝大多数主流协议，实际上都依赖某种形式的混合智能合约。课程主要以以太坊为例进行讲解，但所学内容同样适用于 Polygon、Avalanche、Fantom、Harmony 等 EVM 兼容链。理解底层原理后，切换链往往只需要改动极少的配置。

在概念层面，课程解释了 DApp（去中心化应用）的含义：通常由多个智能合约组成，是 Web3 世界中的基本应用形态。同时介绍了 Web3 的历史演进：Web1 是开放但静态的网络；Web2 是动态但高度中心化的平台；Web3 则试图在动态交互的同时，重新回到去中心化、用户拥有资产与协议的模式。

在价值层面，Patrick 将智能合约的核心意义总结为一句话：**“信任最小化的协议”，或者更直观地说，“不可违背的承诺”**。现实世界中的大多数经济与社会活动，本质上都是基于“承诺”的。但传统系统中，这些承诺往往会被破坏，比如金融危机、银行挤兑、平台操纵市场等。智能合约通过不可篡改、自动执行和完全透明的机制，使“作恶”在系统层面变得困难甚至不可能。

在技术特性上，智能合约具备去中心化、透明性、效率高、安全性强、不可篡改等优势。交易和结算几乎可以实时完成，不再依赖中介机构；数据公开可验证；系统更难被攻击；资产由用户通过私钥直接控制，而非托管在平台中。

课程后半段开始进入实践，包括钱包的创建与使用。以 MetaMask 为例，介绍了钱包的基本概念、助记词（Secret Recovery Phrase）、私钥、公钥地址之间的关系。助记词相当于所有账户的总钥匙，而私钥则是单一账户的控制权。丢失私钥或助记词意味着永久失去资产控制权，因此安全管理极其重要。课程建议在学习和测试阶段使用“测试钱包”和“测试网络”，避免任何真实资金风险。

同时引入了区块浏览器（如 Etherscan）的概念，用于查看地址、交易和区块数据，这是理解区块链运行机制的重要工具。课程后续将通过测试网和本地网络，逐步带领学习者完成真正的链上交互。

### **The Role of Web3 Media Practitioners in the Ecosystem**

**1\. Information Distributors**

This role is relatively straightforward. Media aggregates the most up-to-date information in the market, including frontline news, opinions, and perspectives from industry leaders. After aggregation, our core task is distribution.

Compared to other market participants—whether investors, traders, or people who are simply curious about Web3 and crypto—media represents one of the **lowest-barrier entry points** into the ecosystem. In this sense, media functions as a **traffic gateway**.

For people outside the space, media serves as a learning platform. For those involved in investment and trading, media often relays market signals such as capital flows, “smart money” movements, KOL opinions, and exchange-related asset trends. Fundamentally, this role helps **reduce information asymmetry** in the market.

**2\. Market Educators**

As I mentioned earlier, for many newcomers, media is the **first point of contact** with the Web3 ecosystem. This naturally gives media a strong educational role, especially for beginners.

On the other hand, even for participants who are already in the market, there is often a lack of deep understanding. For example, when people first enter Web3, they may not fully understand DeFi. Media can help by breaking down protocols, interpreting data, and explaining the causes and potential consequences behind major events.

People may be active in the market, but not fully aware of the background or logic behind what is happening. This is another area where media plays a critical role.

**3\. Value Discovery**

Many people might assume that value discovery is mainly the job of exchanges. However, I believe exchanges focus more on **price discovery**, rather than value discovery.

Value discovery can take multiple forms—both in terms of content and assets. In the market, assets range from large ones like BTC and ETH to smaller ones such as meme coins. What media can contribute is different from what exchanges do.

Exchanges are largely off-chain channels where information is not always fully transparent. Media, by contrast, can provide insights into smart money flows and behavioral signals. For smaller assets or meme coins, media can also highlight where attention and narratives are forming.

In addition, across more conventional projects—whether in DeFi or other sectors—different narratives and sectors rotate over time. Media can help identify where current narrative momentum is, which protocols are attracting the most attention, and which sectors may have stronger future potential. This allows participants to gain early signals and position themselves ahead of broader market movements.

‘解构’这个词，可能在非人文背景的听众听起来，会觉得特别像人文学者常用的一个词。但其实我们自己在本科毕业之后，基本就很少再用这个词了。不是因为不用做解构，而是因为它已经变成了人文学科里的一个默认前提。就算没有人再提‘解构’，我们做的事情，还是在解构研究对象、解构理论，也在解构日常生活的方方面面。

今天我想把这种思路分享给大家。希望在分享结束之后，大家能试着用一个更大的视角，去看你们现在正在做的事情——不管是工作，还是正在学习的技术。它都可以被扩展到很多其他方面，并且有很多人在用各种方式尝试去扩展它。

那这些人是怎么把它扩展出去的？我们又该怎么看待它？我觉得这其实可以提供给大家一种思考方式，这也是我自己在做 Web3 研究过程中的一些心得分享，也非常欢迎大家之后跟我一起讨论。

今天我想从 Web 3 开始聊起。Web 3 其实是一个挺模糊的概念，它大致可以从三个层面来理解：平台、经济，以及社会。

![image.png](attachment:9cc6d674-5e19-4b55-b7d8-0ace91d02db5:image.png)

先从平台，或者说网络本身开始。相信在座的各位应该都已经知道，或者至少听说过很多用来定义 Web 3的说法，不管是你在路线图里看到的，还是各种关键词，比如去中心化、确权、信任、P2P。

同时你可能也会注意到，我们一方面会说 Web 3，另一方面又会说 Web 3.0（Web Three Point Zero）。那这两者之间到底有什么区别？

![image.png](attachment:d922e4aa-7ad8-45c8-ae3b-a35c98b85e67:image.png)

先请大家看一下屏幕上的这位。这是世界上第一个提出“Web 3”概念的人，大家可能都认识他——蒂姆·伯纳斯-李（Tim Berners-Lee），\*\*万维网（WWW）\*\*的创始人。他发明了 HTTP，让网络可以传输内容，并通过超文本链接把信息连接起来，是一位计算机科学家。

但其实在他当年提出这个概念的时候，用的术语正是 Web 3.0，只是它的含义和我们今天所说的 Web3 完全不一样。他所指的 Web 3.0，是“语义网”。他的设想是：基于超链接这种互联网技术，在上世纪九十年代，人们就已经开始想象，未来是否可以让机器访问人类在网络上的所有内容，对这些内容进行处理，通过语义层面的处理，进而自动操作和运转。到了那个阶段，整个网络就像一个整体的智能系统。

当然，他当时并不会用“智能体”这样的词，而是把这个设想称为 Web 3.0。某种程度上，这个设想今天已经基本被人工智能实现了。

![image.png](attachment:2c32632f-0722-4b21-96aa-58c6f342a7de:image.png)

如果我们沿着思路继续，会发现其实在 Web 3.0 还没有这么火、甚至在 “Web3” 这个词本身还没有被广泛讨论之前，它就已经被不断地“指派（Assign）”、被赋予过各种不同的技术含义。

如果大家回头看一些早期的报道，会发现这个词曾经被用来指互联网本身，也被用来指物联网、移动互联网，后来又被用来指平台、媒体等等。虽然在那个阶段，其实没有多少人真正相信这套叙事，也没有像今天这样密集、火爆地讨论 Web3 这个概念，但很多人一直都在做相关的尝试。他们普遍有一个共识，就是互联网会不断迭代，会不断迈向下一个阶段。

![image.png](attachment:6701eaf3-2a66-4960-9fa7-4e988515d3cf:image.png)

真正引爆我们今天对 Web3 理解的，其实是 2014 年。那一年，Gavin Wood——以太坊的联合创始人之一——提出了我们现在所说的、基于区块链的 Web3 概念。他当时所说的 Web3，并不只是指区块链本身，而是一整套新的互联网系统。

这套系统主要由三部分构成。第一是区块链，尤其是以以太坊为代表、具备智能合约能力的可编程区块链；第二是去中心化的文件存储系统，比如我们现在比较熟悉的 IPFS，当时也有其他不同的技术路径；第三是去中心化的点对点信息传递系统（P2P）。

当这三套系统结合在一起时，它就有可能改变我们对互联网大多数用途的理解。文件可以在区块链上，程序可以在区块链上运行，信息传递也可以通过去中心化的方式来完成。基本上，我们今天在互联网上能想象到的很多事情，都被认为是可以迁移到区块链之上。

也正是在这样的技术基础之上，围绕着以太坊智能合约，大家开始重新想象：互联网是不是可以进入下一个阶段，进入一种新的状态。这个背景，相信大家现在都已经非常熟悉了。

![image.png](attachment:6fba0a5d-2f06-47ab-ad86-f49b0a809360:image.png)

我想先简单总结一下刚刚说到的这些内容，然后和大家一起分析一下，这里面其实隐含着的一个规律。

Tim Berners-Lee 在提出 Web 3.0 的时候，给它起了一个名字，叫“语义网”。他之所以要提出这个概念，其实也和当时流行的 Web 2.0 有关。在他提出 Web 1.0 之后，很多人开始谈 Web 2.0，把它理解为一个更快、更平台化、内容更加丰富的互联网形态。

所以 Tim Berners-Lee 对 Web 2.0 这个说法其实是非常不服气的。他觉得“Web 2.0”本身就是一种炒作，因为在他看来，它和 Web 1.0 在本质上并没有区别，和他当年所创造的互联网也没有本质上的不同。

正因为如此，他试图去想象一种更远的互联网形态，并以此作为一种对抗：你们现在所说的这个阶段，如果放在一个更远的未来形态里去看，其实和 Web 1.0 是非常相像的。相比之下，真正的差异，应该是和那种拥有智能体、能够自动处理信息的 Web 3.0 相比而言的。而在这个意义上看，Web 1.0 和 Web 2.0 之间的技术差别，其实并没有那么大。

同时也可以看到，“Web 3.0”这个词在历史上曾经被赋予给非常不同的技术路径。刚才已经看到过，它是如何被用来定义一种基于区块链的、去中心化的互联网，并逐渐和 Web3 这个概念合并在一起。在实际意义上，“Web3”或者“Web 3.0”已经基本融合，成为了今天区块链行业的一种别称，或者说雅称。

你们在网上可以搜到很多以 Web3 或 Web 3.0 为标题的白皮书和政策文件，这也说明，中国政府对区块链长期以来其实是一种非常模糊的态度：一方面总能找到大量支持性的文件，另一方面也同时存在着很多反对加密货币、反对发币炒币的政策，这两者是并存的。

在有了这样一个历史视角之后，会发现，其实无论是 Web3、Web 3.0，还是“互联网的下一站”，这种想象在历史上一直都存在，人们一直在做这件事。那问题就在于，我们今天在做的这件事，到底是什么？它和过去有什么不一样？

在回答这个问题之前，我觉得我们首先要回答的是：为什么我们现在要去推广 Web 3.0？

因为当我们今天在谈 Web3 的时候，很多时候其实是在回应 Web2 的不足，或者说 Web2 所带来的风险。这些风险通常会被概括为平台化的风险，或者中心化的风险。

这一点其实大家都很熟悉。第一，平台经济会对参与者产生剥削。很多平台看上去是免费使用的，但实际上是在剥削所有参与其中的人，尤其是内容生产者。

第二，它会对我们的隐私和安全构成威胁。Facebook 就是一个很典型的例子：它一方面声称不会出售用户数据，另一方面却将数据转手给英国的公司，甚至试图干预选举。

第三，我个人很喜欢一个词，叫 _enshittification（💩）_，中文通常翻译成“垃圾化”，或者“屎化”。这个词在北美讨论中非常流行，它指的是这样一种现象：由于平台必须满足资本回报率的要求，它在经济模式上是内在矛盾的——它需要先通过提供优质服务吸引用户进入，然后再不断让服务变差、变差。因为它没有动力持续冒险，也没有动力真正改善用户体验，而是必须把精力集中在提升变现能力和边际收益上。所以，一个由单一公司控制的中心化平台，几乎不可避免地会提供越来越差的产品。

当然，这些反对平台化、反对中心化的论点都非常常见，而且在很大程度上也确实是成立的。但如果回到之前看到的那些图示，其实 Web 2.0 并不等同于平台。没有人真正把 Web 2.0 定义为平台，或者定义为一个中心化的互联网。它只是一个既可读又可写的互联网形态，在实践中很大程度上呈现为平台化，但它本身并不必然是平台。

（Wait a second…）但在这一轮 Web3 的叙事中，Web2 却被重新界定成了“平台”。也就是说，我们所处的这个当下互联网阶段，被明确地通过一个非常遥远的未来构想来重新命名和定义。（Wait a second…）这件事情和 Tim Berners-Lee 当年第一次提出 Web 这个概念时，其实做的是同一件事，这是第一点。

第二点是，我们其实并不知道所谓的 Web3，或者说一个“严格意义上的 Web3”，到底什么时候才能真正实现。

如果回到Gavin Wood 这张图来看。当他在 2014 年提出 Web3 这个概念的时候，大家想象的是，未来的互联网可以整体搬到区块链之上。但到了今天，现实情况其实并不是这样。

在座很多朋友可能都是开发者，或者至少对区块链行业有一定了解。大家应该都知道，现在真正能用得上的区块链应用，大多采用的是 on-chain 和 off-chain 混合的模式，并不可能把所有数据都完全放在链上运行。

即便是做得相对成熟的产品，比如 Polymarket，它的使用体验其实也非常糟糕。这一方面和产品设计有关，另一方面也和区块链本身在带宽、速度、安全性等方面的技术限制有关。

![image.png](attachment:de9fd093-fafc-4573-8c43-4620f18b5df8:image.png)

我这里举一个例子。这张图是 forcaster 的官方架构图。你可以看到，它其实和大多数我们现在真正能用得上的所谓 Web3 应用一样，都还是包含中心化服务器的部分。但他们会有意识地把一些数据、或者某些关键功能，设计在区块链上。

比如在 forcaster 里，如果你付费成为会员，你的用户数据是可以放在链上的。这样一来，即便他们倒闭了，或者你想把数据取走，你都可以随时带走它，而不会像 Twitter 那样，平台可以直接删除你的账号。

![image.png](attachment:11875014-c4c2-4800-a49f-58fdb5da40f4:image.png)

这也是我自己的一个思考：当我们说 Web3 是一种不同于平台互联网的新的网络模式时，它到底指的是什么？

如果只是用“去中心化”、“点对点”、“确权”这些相对模糊的概念来定义它，其实并不能很好地反映我们当下真正面对的情况——也就是：一些互联网应用部分搭建在区块链之上，但同时又和传统互联网形式保持着非常紧密的关系。某种程度上，那种一个词一个词、阶段式的命名，更符合刚才提到的定义“当下”，更服务于定于平台互联网，而不是在准确描述我们现在所处、或者未来可能共同参与的区块链互联网世界。

所以，首先我们需要考虑的是它的**去中心化程度**。就像刚才 forcaster 的例子一样，它并不一定是一争到底、完全去中心化的状态，而更像是一个连续的轴。

在这里用个稍微学术一点的说法，叫 _distributed_，也就是分布式网络。如果大家没有做过网络研究或者媒介研究，其实不理解这个术语也完全没关系。但右边这张图里有一个很经典的例子，展示了三种不同类型的网络结构。

在学术语境中，_decentralized_ 其实是 _distributed_ 的一个子集。也就是说，用 _distributed_ 这个概念，反而更能涵盖区块链网络的实际形态，而不仅仅是“去中心化 _decentralized_”。

如果我们把 Web3 理解成一条轴，在这条轴上分布着不同程度的分布式、或者去中心化应用，那么其实也可以反过来理解：Web2 也可以是一条轴，Web1 也可以是一条轴。

对 Web2 而言，如果我们按照现在这个语境，把它理解为高度基于“平台”的互联网形态，那么它一个非常核心的特征，其实是**可编程性**。

这一点在很多关于平台的研究都有讨论。因为“平台”这个词在日常语境里已经被用得太多了，以至于我们很少再去追问它在计算机意义上的定义。但在计算机里，一个东西是否构成平台，很关键的一点就是：它是否允许你与之互动、是否可编程。

这也和我们刚才提到的 Web 演进有关——从最早的只读，到后来的可读可写，而“可写”本身，其实就是一种程度上的可编程。当然，在这个程度上它们之间是有区别的。

所以，Web3 也许可以这样来看：我们现在所说的这种更群众化的互联网，其实是建立在一个**可编程的互联网**之上的，这是其中的一步。再往前推一步，甚至可以说还有一个“ 第 0 步”，也就是**可连接的互联网**——前提是我们真的有过网络连接。等会儿我会举一个具体的例子。

左上角这张图应该已经看过无数遍了，就是 Vitalik 画的区块链“不可能三角”：去中心化、扩展性和安全性。其实这三者，和我刚刚讲的 Web1.0、Web2.0 到 Web3.0 的演进逻辑之间，是有一些对应关系的。

比如说，去中心化对应的是分布式结构；扩展性更多指向基础设施层面的可连接性；而安全性和可编程性，其实是一组相互牵制的概念——当系统的可编程性越强，它的安全性往往就越难保证，这两者是彼此制衡的。

我并不是在论证它们之间存在某种严格的内在逻辑关系，只是觉得这种对照本身很有意思。它让我们看到，区块链开发者在设计和编写程序时所遇到的那些限制，其实和互联网在整体发展过程中不断暴露出来的结构性限制，是一脉相承的。

一个很具体、也很现实的例子，是我之前在uncommons做过的一项研究，关于缅甸的经济状况以及加密货币的使用情况。可能有些人不太了解，缅甸从 2021 年发生了军事政变，他们经历了很多我们认为“加密行业可以解决”的问题，比如极其严重的通货膨胀，比如对平民的高度监控、网络审查等等。从表面上看，这些问题好像都非常适合用加密货币或区块链来应对。一方面是因为泰国本身的环境，另一方面也是因为清迈聚集了大量缅甸难民，他们也在那边自发组织各种交流。我是在 2024 年去到那里的，当时已经有很多讨论，但这些讨论往往都会停在同一个地方——缅甸的朋友会说：我们会周期性停电，而且没有稳定的互联网。但问题在于，一旦停电，这一切就中断了。他们并不能随时随地保持在线。即使我们希望他们去使用加密货币、使用钱包，在日常生活中其实也很难真正落地。

我想通过这个例子强调的是：现在所谈论的去中心化互联网，仍然是建立在 Web1、Web2 的基础之上的。即使区块链系统本身已经设计得非常完整，它的扩展性依然会受到最基础的可连接性所限制，而这个问题并不是加密货币或者区块链行业本身能够解决的。从这个角度来看，也许可以帮助我们更宽广地理解 Web3。我个人会认为，至少在目前阶段，Web3 和 Web2 并不是取代关系，而是一种共生关系。

但与此同时，Web3 所代表的也不仅仅是网络形态本身，它正在逐渐成为一种用来描述区块链行业如何自我资助、如何支持内部项目、以及如何让整个系统持续运转的“**经济模式”，乃至规律**。

![image.png](attachment:b2de8261-115c-4dcd-9074-0f382b23de0f:image.png)

大家在残酷共学的学习过程中，应该也已经接触过 public goods / commons 这些概念。那我们现在在 Uncommons 内部，其实也一直在讨论公共物品的问题。

所以，虽然在区块链行业里，我们经常把“公共物品”挂在嘴边，但它很多时候更接近的是“共有资源”，也就是 commons。其实我觉得不必过度纠结这两个词的边界，但有一个区分在区块链语境里反而比较少被提到：在传统经济学中，public goods 通常被认为是由国家提供的，是一种自上而下的结构；而 commons 更多是由社区自己提供的，是一种自下而上的组织方式。也正因为这样，近几年有一些学者会更强调 commons 这个概念。

顺带一提，我之前也参与过一本书的翻译——Peer to Peer: The Commons Manifesto (Critical, Digital and Social Media )——这本书是由 Michel Bauwens、Vasilis Kostakis 和 Alex Pazaitis 三个人合作的，大概是 2019 年出版的。那时候，开源软件、数字制造、3D 打印这些概念都还比较新，大家普遍觉得，可以基于这些实践发展出一套新的经济模式。到今天为止，其实这些人还在持续实践点对点的经济模式。

![image.png](attachment:a07a3867-36e4-4618-90f1-005d2def2c87:image.png)

如果大家看过 GCC 的那份报告，会看到里面提到：Web3 语境下的公共物品，在精神上既和公共物品有关，也和经济学里的 commons 有关联，但它还有两条额外的定义。这两条定义主要来自 Vitalik 的一篇论文，也就是右下角这篇。

这篇论文里，他提到了公共物品的两个特征：**一是边际回报递增，二是正外部性**。在 GCC 的报告中，几位编辑其实也对“边际回报递增”这一点打了问号，坦率地说，他们也不太确定这具体意味着什么、或者是否真的成立。但我想先把这个概念放在这里，等结合后面的讨论，我们大概可以回过头来理解，边际回报递增的可能理解。

正外部性可能大家比较熟悉，它指的是：我们在为自己创造收益的同时，不仅不会对外部造成损害，反而会对外部产生好处。比如说，我在区块链上做了一个开源的基础设施工具，它可以帮助别人搭建他们的程序，或者发展他们的业务；与此同时，我自己也可能从中获得收益，不管是代币收益，还是运营层面的收益。这就是一个典型的正外部性。

![image.png](attachment:5abe856c-aba4-4bb1-8758-8755f4fa17b4:image.png)

基于这些概念，我们会发现，区块链世界里的经济模式，其实和传统公司的制度非常不同。最早产生这种分野的，就是 DAO 这个概念，以及 The DAO 那段历史：最初它是以 DAO 的形式，让参与者共同决定如何分配在以太坊生态中获得的收益，并把这些资源再投入到新的项目中。后来因为被黑客攻击，引发了以太坊的硬分叉，这个项目本身也在几个月后名存实亡。但这种模式并没有消失。直到今天，世界各地仍然有很多 DAO 在承担资源分配和投资的功能，也有不少 DAO 转向了更偏社区、偏公共领域的发展方向，后面也会举一些例子。

在以太坊生态中，后来出现了像 Gitcoin 这样的机制，引入了二次方投票，相关讨论大家应该已经非常熟悉了。最近还有一些新的尝试，比如意识到投票本身成本很高，大家不可能了解所有项目，于是开始尝试引入人工智能，来协助改善整个投票和决策过程。虽然这些尝试未必都成熟或有效，但从一个观察者的角度来看，我还是觉得它们非常不一样。

如果你把以太坊当成一个整体的经济实体来看——它的市值一度超过腾讯——你会发现，在这样一个体量之下，它内部的资源分配机制却异常花哨、多样，几乎可以不断试验各种可能性。这在其他大型经济体内部是非常少见的。即便我们经常批评以太坊基金会仍然相对中心化，但整体来看，这套结构依然非常特殊。

当然，在这个生态里也有大量的 public goods funding，同时也存在很多“赏金猎人”，甚至有人会利用规则漏洞获利——只要有规则，就一定会有人钻空子。这些现象大家可能比我熟悉。

我真正感兴趣的，是把区块链经济内部的价值系统，放进整个世界正在运行的各种经济系统中，去做一个横向比较。这是一个非常初步的设想，也完全是 open 给大家讨论的。

![image.png](attachment:641b08ef-5673-4417-bbf2-738f064eda1c:image.png)

接下来这张图来自一位经济学家 佩里梅林 （Perry Mehrling），他曾在哥伦比亚大学任教。他提出的是一种相对小众的（相对于主流经济学）、以货币本身的条件和流动性（liquidity）为核心的经济学理论。他画了这样一个金字塔：中间是现金，上面是黄金，下面是各种金融衍生物。

他的理论大致是：当经济上行时，这个体系里的所有东西都会被当作“货币”，并不断向下展开，这些东西都是价值的标的物，或者按照马克思的说法，交换价值映射在实用价值之上（当然不止于此），当经济上行的时候，这个金字塔会扩张，你可以想象成两只手臂张开，变得又扁又宽。大家会往下面去使用，会用在更多的衍生品或者证券上；但当经济下行、不确定性增加时，资金会向上收缩，回流到更安全的资产，比如黄金，整个金字塔就会变得又窄又高。很多原本承载使用价值的东西无法被覆盖，就会失去资金支持，企业倒闭，这些情况也就随之发生。

那问题就来了：**加密货币，在这个层级结构里，处在什么位置呢？**

这里有两个维度需要考虑。第一是加密货币本身的特点，学术界一般称为“数字金属主义”和“共用的基础设施主义”。数字金属主义认为，加密货币通过算法创造了类似黄金样子的稀缺性，这种稀缺性决定了它只能被当作投资品，而不能真正成为现金（cash）或交换媒介。基础设施互助（or 中立）主义（Mutualism）则认为，加密货币是一个点对点交易工具，本质上是为了使用而存在的，不是为了投资。

而经济学上，使用的钱和投资的钱是两种完全不同的东西。如果认为货币应该不断被使用，它应更接近交换价值，应该往下走；而如果它是数字金属，它就往上走。这两者广义上都是“钱（Money）”，但实际上完全相反。

具体会发生什么呢？我有四个构想。

![image.png](attachment:c676bd11-0279-409d-bbce-58986ce9caee:image.png)

第一，加密货币的生态可能保持数字金属的特性，离使用价值较远。这种情况下，有两种可能：一种是它慢慢与传统法币框架结合，比如美国（or 主权政府 or 基于主权政府的体系）正在推动的合规化趋势；另一种是它保持独立、偏加密朋克，不依赖政府，形成自己的生态系统。

以太坊在某种程度上就是这样一个多中心模式：一方面与法币经济结合，合法合规，需要交税；另一方面存在全球通用、无需监管的加密货币体系。这两套体系内部又会衍生自己的顶层投资品，比如 USDC 或其他衍生品，再往下是各种衍生品，债权、权益等。

![image.png](attachment:c7285bc4-ab89-4e11-b6ec-b89369dc4ee7:image.png)

第二种可能是直接用区块链技术对应具体的使用价值，解决现实问题。这类项目比较少，但存在。比如一些本地项目，会用区块链来管理共享数据、发放证书、碳排放证明等，在局部层面创造价值（make a difference）。以太坊在推动这种意识形态：让加密货币形成一个全球通用的价值宇宙（Cosmo-localism），同时与本地价值体系结合。

![image.png](attachment:39c3e4c7-8c59-4884-8cdb-121ad927ac8b:image.png)

接下来谈谈 Web3。Web3 最初是一个网络形态的概念，但慢慢它也构成了网络内的经济系统，甚至成为社会形态的代名词。它的核心理念是去中心化社会，用去中心化的互联网技术推动一种新的社会形式。

以太坊的 DAO 就是一个例子。最早在比特币社区有 DAC（Centralized Autonomous Corporation），是公司化、股东制的模式。后来演变成 DAO（Account Autonomous Community），强调平等，每个人投票权相等，而智能合约提供自动化信任，不依赖中心化管理。当时 Vitalik 在定义基于智能合约的DAO，他的其中一个核心观点是——No Common Language Test——组织中没有任何两个人可以说同一个语言，还是能够运行，就是一个fully ledge 的DAO。此时，DAO 不仅是经济资助模式，更是一个基于自动化、完全平等主义的社会形态，这个形态在以太坊社区有些像投资公司，或者开放基金的地位，但也有人会将其推向国家，比如_巴拉吉_·斯里尼瓦桑 （Balaji Srinivasan）的《The _Network State》（2022）_。

![image.png](attachment:bbd90896-97af-4413-8ba4-51e1284e08ef:image.png)

我觉得 Web3 被接受为一套社会体系，这一点可能是现在加密文化里不可或缺的部分。这里有一张很大的图，是台湾的 FAB DAO。我觉得 DAO 在东南亚，特别是在华语生态圈里，有一个很明显的特点。国内的话，由于不能发币，因此很多 DAO 都是非盈利的。而在香港、台湾，虽然有些 DHK 可以发币，但似乎也都在走非盈利的路线。这些 DAO 更多是在构建一个公共社会或者公共领域，这个领域可以实验和囊括 Web3 提到的各种意识形态和可能性——自由、民主、分布式、加密、朋克……各种各样。

![image.png](attachment:9680f353-c290-403a-a32b-4fb26fdeb1aa:image.png)

在这张图里，大家可以看到，它几乎像一本巴洛克式的百科全书，把所有相关的意识形态和议题都囊括进去了，我觉得做得挺漂亮的。

![image.png](attachment:e9f1dabf-5aca-4a34-a2cc-6b328858da9b:image.png)

但是作为学者，尤其是人文学者，这时候就不得不引入一些（或是烦人的）历史。这里有一本很有名的书，叫 From Counterculture to Cyberculture，讲的是互联网早期的历史。去年 Uncommon 还做过一期读书会专门聊这本书。大家可能听说过，乔布斯就受过一本叫 _The Last Whole Earth Catalog_ 的书影响很大。这本书在加州硅谷风靡全国，它代表了当时的反文化潮流——反越战、向往东方神秘主义、迷幻药、迷幻音乐——是一整套社会运动。这场运动很大程度上影响了互联网和个人电脑的诞生。在那之前，大家都把网络和电脑看作集权的象征，因为电脑庞大，网络是军事项目。但在这场运动中，人们发现可以通过技术探索更好的人类生活方向，而这些人恰恰又是后来研究个人电脑和网络的人，于是慢慢塑造了这些的形态的诞生。

这本 _The Last Whole Earth Catalog_ 本身也是一本目录型出版物，不是文章、采访为主，而是告诉你在哪里可以买到建造自己社区的工具——一个从零开始、离开主流社会、完全自建的嬉皮士式社区。那个时期还有另一位思想家巴克明斯特·福勒（Buckminster Fuller），他设计的球形建筑，用最少资源获得最大空间，没有中心点，这种理念风靡一时，主要在七十年代。很多人回到故土去建造自己的公社，通过网络找到所需工具。

到了八十年代，这些运动逐渐平息。一方面是钱用光了，很多参与者是富二代或继承了遗产；另一方面，科技公司开始真正赚钱。当时的 _The Last Whole Earth Catalog_ 关闭了，但人们转移到了别的社区，比如现在的连线（Wired）杂志，它逐渐和主流经济、金融资本结合，而最初的新公社运动和愿景则被边缘化。技术从嬉皮理想转向追求意识形态和经济自由，这种逻辑延续到今天的加州意识形态，即技术本身是要享受意识形态和经济自由的。

![image.png](attachment:9a7ef2dc-42a1-4c75-8392-4e0b65826ff7:image.png)

我觉得这个Uncommons里的笔记对现在的加密生态很有启示：把不同领域的人放在一起，通过技术推动社会进步，这在互联网早期已经发生过。当时，人们普遍相信网络与个人电脑将推动深刻的社会变革。在文化层面，这种信念表现为对现实的逃离以及对太空、未来的想象；而在经济层面，则伴随着大量投入，却未必能够获得相应的回报。类似的现象在 Web3 中同样可能出现，是否会持续发生，仍有待观察。

最后，我想分享一个小案例，把区块链基础用来解决实际问题。左上这张图展示的是缅甸难民到泰国的情况，他们需要携带二十多本证件，每一本都很难获得，因为在缅甸，很少人能拿到护照。这些证件中，有一个粉色卡片（pink card）是合法工作的证明，价格高得惊人——相当于泰国本地人半年工资，对于缅甸难民而言，可能要一到两年工资。这个不平等反映了身份在世界上是多么奢侈。但同时，有身份证件也意味着被纳入国家控制网络。在美国最近的反移民浪潮中就很明显，即便很多无证之人，联邦政府也没有权利去赋予证件以及公民的权利。

在缅甸，罗兴亚地区的情况更严酷，当地人没有政府认可的身份，他们生活条件极其艰难，这是一个殖民遗留问题。自 2018 年起，有一个计划让这些人通过社区互认的方式，把身份信息保存到区块链上，形成 NFT，叫做罗兴亚计划。这个系统需要代币经济（tokenomics）运作，因此尚未完全投入使用，执行效力也无从所知了；并且如果仅仅被记录而不被政府承认的，或之后也不起作用的话，这些也只是被记录而已，但这是目前最好的方式保存具有公信力身份信息的方式。这个例子很小，但希望激发大家思考—— 技术可能解决实际问题，也可能激发新的社会想象，只要我们它们放在更大的价值空间中。Web3领域是一个口号和概念特别丰富的地方，所以解构这一个技能就显得更加重要。解构的思考方式不光给予我们更广更准确的视野，也能带来意想不到的启发和灵感。

谢谢大家！

Alchemy「Road to Web3」第二周的导入与实操核心，主题是 **DeFi（去中心化金融）与一个完整的“Buy Me a Coffee”DApp 示例**。讲者首先说明背景：DeFi 被视为一种用**智能合约替代传统银行和金融机构**的技术路径。虽然这是一个宏大的说法，但在课程中会通过非常具体、可运行的代码示例来理解其最基本的原理：用代码自动化资金流动，并在此基础上构建应用。

课程一开始对学习者的前置条件做了预期管理：如果熟悉编程语言会非常有帮助，尤其是 JavaScript，但即便只理解变量、循环、类这些基础概念，也足以跟上。课程设计是“照着做就能跑起来”，同时 Alchemy 社区（Discord、Telegram、Twitter）会提供支持，强调这是一个**可复制、可扩展、以实践为导向的学习路径**。

在解释 DeFi 之前，讲者先澄清了“加密货币到底是什么”。它并不是实体的金属币，而本质上是一个**公开、分布式的账本**。通过 ERC-20 合约示例说明，核心状态其实就是一个 balances 映射：把“地址”映射到“余额”。当一笔交易发生时，区块链会记录事件、更新状态，例如一个地址余额减少，另一个增加。这个账本是去中心化维护的，没有任何单一控制者，所有节点共同验证。这种结构的关键意义在于：**因为它是软件构建的公共账本，所以可以在其上层构建非常复杂而自动化的金融逻辑**，这正是 DeFi 的基础。

随后课程明确本周的学习目标：从零编写一个自定义智能合约，允许他人用 ETH 给你“买咖啡”、附带留言，并允许合约部署者提取收到的打赏。工具链包括 Hardhat 与 ethers.js（智能合约开发与交互的主流工具），前端将使用 Replit 快速搭建，最终实现一个可在测试网上被他人真实交互的网站。同时，课程属于一个为期十周的学习计划，每周完成挑战可以获得不可转让的 Proof of Knowledge NFT，作为学习轨迹的链上凭证。

在正式编码前，讲者展示了最终 Demo：一个类似 “Buy Me a Coffee” 的网页应用，但资金流转完全通过加密钱包和智能合约完成。用户连接 MetaMask 钱包后，可以输入名字和留言，用固定数量的 ETH 发送打赏。交易被确认后，留言会从区块链读取并显示在页面上，附带时间戳。这一演示强调了几个关键点：前端通过钱包发起交易，智能合约接收 ETH 并记录数据，交易被区块链确认后，状态变更即可被读取并展示。

接下来是整体架构说明：系统分为前端网站与“后端”的智能合约层。虽然它不等同于传统 Web2 的后端，但所有业务逻辑、资金托管、数据存储都发生在合约中。合约的核心功能包括：接收咖啡打赏、存储并返回留言列表、以及只允许合约部署者提取合约中的 ETH 余额。

在环境搭建部分，课程强调这是“最痛苦但必要”的阶段。使用 npm 作为包管理工具，通过 nvm 管理 Node.js 版本，确保开发环境一致。推荐的版本是 Node 16.13.1 和 npm 8.x，以避免调试问题。所有步骤和版本信息都可以在 Alchemy 文档中查到。

随后进入 Hardhat 项目初始化流程：创建项目目录、npm init 生成 package.json，使用 npx hardhat 创建基础示例项目。Hardhat 会自动生成 contracts、scripts、tests 目录以及配置文件，并安装 ethers、waffle 等依赖。讲者详细解释了目录结构的意义：contracts 存放 Solidity 合约，scripts 用于部署和交互脚本，hardhat.config.js 控制 Solidity 版本与网络配置。

核心部分是 **BuyMeACoffee.sol 智能合约的编写**。原有示例合约被删除，改为自定义合约。合约中首先定义了一个 Memo 结构体，用于保存每一笔咖啡打赏的信息，包括发送者地址、时间戳、昵称和留言内容。同时定义了一个事件 NewMemo，用于在链上记录日志，方便前端或脚本监听。合约还保存了一个 payable 的 owner 地址，用于记录部署者身份，以及一个 Memo 数组，用来存储所有留言。

构造函数在合约部署时执行一次，将部署者地址保存为 owner。由于需要向该地址转账，必须显式将其声明为 payable 类型。核心函数 buyCoffee 被声明为 public 和 payable，允许任何人调用并附带 ETH。函数内部首先通过 require 校验打赏金额必须大于零，然后创建 Memo 结构体并存入数组，同时触发 NewMemo 事件。资金不会立即转给 owner，而是累积在合约余额中。

合约还实现了两个辅助函数：withdrawTips 用于将合约内的全部 ETH 转给 owner，getMemos 用于返回所有留言。前者虽然是 public，但无论谁调用，资金都会发送给 owner；后者是 view 函数，只读取链上状态，不消耗额外 gas。通过这一设计，课程完整覆盖了 Solidity 中的状态变量、结构体、事件、构造函数、访问修饰符、payable、以及链上存储与日志的基本概念。

在合约完成后，课程通过一个 Hardhat 脚本（buy-coffee.js）演示如何与合约交互。脚本首先定义了一些辅助函数，用 ethers.js 读取地址余额并格式化输出，以及读取并打印链上存储的 Memo 数据。主流程中，脚本获取 Hardhat 提供的测试账户，部署合约，打印初始余额，然后模拟多个账户调用 buyCoffee 发送打赏，再检查余额变化，最后调用 withdrawTips 并验证资金成功回到 owner。整个过程清晰展示了：**链上状态变化、合约余额变化、事件与数据读取之间的对应关系**。

讲者特别强调，这个脚本与未来前端调用合约的方式在逻辑上是高度一致的，只是账户来源和调用环境不同。理解这一点，意味着你已经掌握了 Web3 DApp 交互的 80% 核心概念。

最后一部分转向真实测试网部署准备。课程引导学员创建 MetaMask 钱包、注册 Alchemy 账户、配置 Goerli 测试网络 RPC，并通过水龙头领取测试 ETH。Alchemy 在这里作为区块链节点服务提供商，承担了 DApp 读写链上数据的基础设施角色。完成这些配置后，编写一个 deploy.js 脚本，将合约部署到 Goerli 测试网，使其可以被互联网上的其他人真实访问和交互。

Greenpills：[https://www.youtube.com/watch?v=T6Rp-9zaagQ](https://www.youtube.com/watch?v=T6Rp-9zaagQ) 这期播客来自 Greenpill Network 的《How to DAO》系列，嘉宾是 **Liberland 的创始人 Vít Jedlička**，一个试图在现实世界中创建“链上国家 / 初创国家（startup country）”的人。整个对话围绕着一个核心问题展开：**如果我们真的相信自由市场、最小政府和链上治理，那国家是否也可以被重新设计？**

Vít 的个人经历深刻影响了他的政治理念。他出生在前捷克斯洛伐克，在共产主义体制下成长。他认为，那四十年的共产主义对社会、经济和人的幸福感造成了巨大破坏。作为对比，他反复提到新加坡：在同一代人的时间跨度里，新加坡从远比捷克斯洛伐克贫穷，变成了人均收入高出数倍的国家。这种差异在他看来并不是文化问题，而是**治理结构、制度设计的直接结果**。

他由此得出一个结论：**人们在治理自己这件事上，往往会做出错误的选择，民主也未必总是最佳解法**。问题不只是“选谁当领导”，而是“系统本身是否鼓励创造财富、自由交换和长期增长”。

在长期推动改革、做公共传播（如他在 2010 年创立的 Reform CZ）后，他意识到，仅靠教育和舆论改变社会是一个跨世代的问题，个人生命长度不足以完成这种转变。于是，他选择了一条更激进的路径：**不再试图说服一个现有国家改变，而是直接创建一个新的国家实验**。

Liberland 正是在这种背景下诞生的。它位于克罗地亚和塞尔维亚之间一块 7 平方公里、双方都未正式声索的土地上。Vít 强调，Liberland 不是“微型国家的玩笑”，而是一个认真对待国家构建的项目。他区分了“nation”和“state”的概念：民族可以没有国家，国家的存在也并不依赖他国承认。根据《蒙得维的亚公约》，只要具备明确领土、常住人口、治理能力和对外交往能力，一个国家在法律上就已经成立。

Liberland 的核心理念是**极小政府 + 自愿税收 + 强个人自由**。政府只负责司法、安全和外交，其余事务全部交给市场和私人部门。但它并不是简单复制美国建国时期的模式，而是试图在制度上更进一步。Vít 认为，传统民主的一个根本问题在于“每个人一票”，不论其对社会的贡献如何。他提出一种结合了共和制、民主制与公司治理的混合模式。

在 Liberland，公民可以否决法律、罢免官员，但不能随意通过新法律来扩大政府权力。治理更像一个“只允许删减、不允许膨胀”的系统。同时，Liberland 引入了一种类似“功绩制股权”的机制：对国家贡献更多的人，在治理中拥有更大的话语权。这在他看来比形式上的平等更接近长期公平。

最关键的一点是，Liberland 并不是把这些理念停留在纸面上，而是**直接把国家治理写进了区块链**。他们基于 Substrate 构建了一条定制区块链，把议会、参议院、总统、总理等治理结构，直接编码进智能合约。选举、投票、权力制衡都在链上完成，选举成本低到几乎可以忽略，而且安全性远高于传统系统。

Vít 认为，一个主权国家就应该拥有主权软件，因此他们没有直接部署在以太坊或 Tron 上，而是选择了自己的链。公民运行节点，本身就是国家运作的一部分。这使 Liberland 成为他所说的第一个“去中心化自治政府（Decentralized Autonomous Government）”。

在播客后半段，对话延伸到了 Justin Sun（孙宇晨）担任 Liberland 总理这一话题。Vít 并不回避 Tron 的高度中心化问题，但他认为 Tron 本身已经是一个“准主权实体”，拥有类似外交能力的影响力。对于 Liberland 来说，这种资源、资本和全球网络的引入，是一个现实且策略性的选择。他更看重的是，这种合作能否推动“用区块链治理国家”这一理念被更多现实世界采纳。

在谈到 Liberland 是否是“微型国家”时，他明确拒绝这个标签。在他看来，微型国家通常不被严肃对待，而 Liberland 更像一个“初创国家（startup country）”。目前已有数十万人申请成为 Liberland 的国民，尽管实际公民人数仍较少，但国家构建的方向已经不可逆。

播客最后给出了明确的行动路径：任何人都可以通过官网或 App 申请成为 Liberland 的居民或公民。你可以通过持有一定数量的“功绩点”参与治理、运行节点，也可以选择实际居住、建设这个国家。对很多人来说，这不是为了投票，而是为了过一种更自由、更少摩擦的生活。

### **Week 2 - Day 5: Solidity 实践与 Scaffold-Eth 入门笔记**

# **Ethereum 开发挑战笔记（DEX、Multi-sig、SVG NFT）**

### **一、DEX（去中心化交易所）挑战**

### **1\. DEX 基本概念**

-   DEX 是智能合约运行的交易平台，允许用户在无需中心化中介的情况下交换 ERC20 代币。
    
-   核心机制是 **自动做市（AMM, Automated Market Maker）**：通过代币储备比例来计算价格。
    
-   交易会产生 **滑点（slippage）**：当交易量大时，价格会偏离理论值。
    
-   用户可 **提供流动性（LP, Liquidity Provision）**，存入代币对，获得交易手续费分成，并获得 LP 代币代表自己的池份额。
    

### **2\. DEX 操作流程**

1.  选择代币对，例如 ETH ↔ Balloon（测试代币）。
    
2.  确认连接钱包（MetaMask 或 Burner Wallet）。
    

进行 **代币交换（swap）**：

-   输入交易数量，系统根据储备比计算输出。
    
-   注意交易过大可能严重滑点。
    

**提供流动性：**

-   存入等值的两个代币（例如 ETH 和 Balloon）。
    
-   LP 代币记录占比。
    
-   可以随时取回并收取交易手续费
    

### **3\. 开发学习点**

-   理解储备比例和价格公式。
    
-   熟悉 approve → swap 的代币授权模式。
    
-   流动性池越大，交易滑点越小。
    

可以尝试修改智能合约：

-   调整手续费。
    
-   修改储备比例（50/50、25/75 等）。
    

-   高级 DEX（如 Uniswap v3）引入 **集中流动性（concentrated liquidity）**，在指定价格范围提供流动性。
    

### **4\. 学习资源**

-   Telegram 群组提供 starter kits、代码仓库、示例 DEX。
    
-   查看其他人的 DEX 实例，理解不同实现方式。
    
-   Hyperstructure 概念：智能合约自动运行，去中心化，无需中央控制。
    

### **二、Multi-sig（多签钱包）挑战**

### **1\. Multi-sig 基本概念**

-   多签钱包要求 **多个签名才能执行交易**。
    
-   形式：m-of-n，例如 2-of-3 表示至少两个签名才能执行。
    

安全性：

-   单个私钥泄露无法操作钱包。
    
-   常用于 DAO、基金会等管理大量资金
    

### **2\. Multi-sig 实操**

创建多签：

-   设置签名者地址（owners）。
    
-   设置阈值（threshold）m-of-n。
    
-   部署智能合约。
    

提出交易：

-   例如向 Vitalik 转账 100 USD 测试。
    
-   生成交易并等待签名。
    

签名

-   可以使用 hash 签名或 EIP-712 签名。
    
-   两个签名确认后，执行交易。
    

Wallet Connect：

-   多签钱包可与其他 dApp 交互。
    
-   通过 Wallet Connect 提交交易，支持多操作调用（multi-call）
    

### **3\. 开发学习点**

-   熟悉 **transaction struct**、签名验证和执行流程。
    
-   理解 **ecRecover** 的签名恢复机制。
    

UI/UX 体验：

-   交易签名和执行分离。
    
-   多签操作相对慢但更安全。
    

现实应用：

-   DAO 提案执行。
    
-   多人管理资金池。
    
-   高级多签可扩展到 5-of-12、12-of-20 等复杂配置。
    

-   **三、SVG NFT 挑战**
    

### **1\. SVG 基本概念**

-   SVG = Scalable Vector Graphics，可缩放矢量图。
    

与传统 NFT 不同：

-   图片直接在智能合约内生成，而非存储在 IPFS 或服务器。
    
-   动态可编程，可通过智能合约修改属性（颜色、形状等）。
    

优势：

-   可组合性强（composable）。
    
-   高分辨率，无论缩放大小都清晰。
    
-   灵活实现 on-chain 游戏逻辑（如 breeding）。
    

### **2\. SVG NFT 实操**

1.  创建 ERC721 智能合约。
    

编写 tokenURI 函数：

-   返回 JSON metadata。
    
-   在 image 字段中直接嵌入 SVG 代码。
    

SVG 动态生成示例：

-   颜色、形状可通过 Solidity 逻辑计算。
    
-   可实现合成 NFT（breeding）。
    

随机性处理：

-   使用区块哈希 + hash 函数生成随机值。
    
-   注意 Solidity 中 randomness 可预测，需要加入 unique ID 防止重复
    

### **3\. 学习点**

-   Solidity 处理字符串和 Base64 编码较低级，需熟练。
    

可将智能合约设计为互动性 NFT：

-   例如“Loogies”可混合颜色生成新 NFT。
    
-   “40s NFT”可通过使用和回收实现公共基金奖励。
    

实践中注意安全：

-   避免 predictable randomness。
    
-   限制 mint 时间以降低攻击风险
    

### **4\. 实例与参考**

-   Sum for Stout NFT。
    
-   Loogies。
    
-   Neolastics（Simon DLR）。
    
-   Ava Stars。
    

### **四、总结**

**DEX**

-   学习自动做市、流动性提供、滑点机制。
    
-   理解 approve → swap 流程。
    
-   可通过修改合约掌握 AMM 定价公式。
    

**Multi-sig**：

**为什么很多品牌在 Web3 听起来很 cringe / 失败**

**📌 核心观点资源与讨论**

🔹 品牌进入 Web3 很容易失败，有几个常见原因：

-   误解社区文化：品牌把 Web3 当作技术工具或营销噱头，而不是社区参与空间，导致活动缺乏真实互动。
    
-   技术与文化理解差距：品牌团队缺乏链上机制、tokenomics、去中心化文化的理解，结果出现 mint 流程复杂、无法融入社区对话等失误。
    
-   没有持续参与机制：许多品牌发完 NFT 或做完一次 campaign 就离开，社区认为这只是“割韭菜式营销”，损害信任。
    
-   Narrative gap（叙事差距）：项目真正做的事情与外界理解的 narrative 之间存在巨大鸿沟，有能力的技术/产品没能讲好故事。
    

这些因素叠加起来，就会让营销显得不真实或“尬”，被社区视为“空洞噱头 + corporate speak”。

**2)Culture Fit vs Product Fit：哪个更重要在 Web3？**

这是一个在营销/叙事圈常被提及但少被系统阐述的辩题，

**观点 A — 在 Web3 文化中，Culture Fit 是基础条件**

Web3 本质是去中心化文化 + 社群参与，所以：

-   产品好不如能建立文化共识
    
-   社区规则/价值决定参与度
    
-   narrative（故事）的主人不是品牌，而是持有者/DAO
    

这点被许多长期从业者在 Reddit & 公众号中提到，例如：

“Web3 marketing isn’t growth hacks; it’s building trust from scratch” — 社区是 co-owners，不接受传统 funnel 模式。

“co-creating brand culture” — Web3 branding 其实强调参与和自我表达，而不是统一品牌口号。

**🔹**

**观点 B — Product Fit 仍是必要条件，但不足以取胜**

-   很多 Web3 项目技术很先进，但因为公开 narrative 不清晰，它们仍然失败或被低估。
    
-   Narrative gap 往往是 产品能力与市场/文化理解之间的鸿沟。
    

**🔹融合视角：Culture Fit + Narrative Fit > 纯 Product Fit**

在 Web3 中：

产品是功能性的入口线，文化是参与性的入口层； narrative 是连结用户与产品意义的桥梁。

没有文化和 narrative 的产品可能会短期增长，但缺乏留存、社区共识和长期扩张。

这恰好可以是圆桌讨论的一个逻辑线：

-   为什么有些产品即使技术好也没起量？
    
-   哪些文化因素（价值共享、身份表达）驱动了用户忠诚？
    
-   在什么场景下 Culture Fit 能超过 Product Fit？

## **📌 在 Telegram 上建组的注意事项（适合运营/社群方向）**

### **1\. 选择合适的**

### **群组类型**

-   Telegram 提供“普通群组”和“超级群组”两种模式，其中**超级群组**可以支持更多成员（最多 200,000 人）、置顶消息、细粒度权限和更强的管理工具。
    
-   如果你的社群目标是增长和公开互动，一般建议直接用 **超级群组**。
    

### **2. 明确定位与规则**

群组名称、头像和简介要清晰说明主题和目标受众，这直接影响用户是否愿意加入和停留。

-   设定清晰的群规，例如：禁止广告/刷屏、讨论范围、语言规范等，能有效避免混乱。
    
-   使用固定置顶消息说明规则与新手引导。
    

### **⚙️ 3.权限与管理策略**

-   合理分配管理员权限，将不同职责分配给不同管理员（发布公告、审核成员、内容审计等）。
    
-   可以设置加入审核、慢速模式等机制减少垃圾信息，保持讨论质量。
    

### **🤖 4. 善用 Bots 与自动化工具**

可以使用 Telegram 机器人来：

-   自动欢迎新成员
    
-   自动发布规则或 FAQ
    
-   过滤垃圾消息
    
-   提供投票、问答等交互功能
    
-   这样的自动化不仅提升效率，也帮助维护长期活跃。
    

### **📈 5. 内容策略与活跃度提升**

-   定期发布有价值内容（比如 AMA、话题讨论、每日问答）能提高成员参与感。
    
-   可使用投票、话题分区（Topics）、贴纸互动等玩法提升参与度。
    
-   内容不能只有“发布”，需要引导讨论和用户反馈。
    

### **🌍 6. 用户体验与沟通策略**

-   新成员进群时建议发送欢迎信息，并附带加入指南、规则说明等。
    
-   对于大型群组，定期进行内容回顾或数据分析（活跃用户、互动率等）来优化节奏。
    

### **🔒 7. 隐私与安全设置**

-   Telegram 提供细致的隐私控制，如隐藏电话号码、控制谁能添加成员等。合理设置这些可以保护用户隐私和群组安全。

这是以太坊「成为 Power User」第一周的第四天，主题是 **NFT**。这一天的目标不是从技术原理开始，而是像真实用户一样去 **买、铸造（mint）、发送和查看 NFT**，通过实际操作来理解 NFT 在 Web3 中是如何工作的。课程延续了之前的逻辑：钱包（MetaMask）、身份（ENS）、资产（NFT）会在不同 Web3 服务之间自然流动。

课程一开始回顾了已经完成的步骤：安装并使用 MetaMask、进行过 ETH 与 DAI 的兑换、完成过链上交易。这些都是今天操作 NFT 的基础。接着通过 OpenSea 这个 NFT 市场，展示了一个重要概念：**你的 Web3 身份和资产会跨平台存在**。即使是 ENS 域名，本质上也是一个 ERC-721 NFT，它会出现在你的钱包和 OpenSea 的资产列表中。如果把 ENS NFT 转给别人，对方就会真正拥有并控制这个域名，这一点和 Uniswap 的 LP NFT（代表流动性所有权）是同样的逻辑。

在介绍 NFT 时，课程强调了 NFT 的核心价值并不只是“图片”，而是 **链上可验证的所有权与来源（provenance）**。艺术家在链上铸造作品，任何人都可以验证这是原始合约、原始作者。即使别人复制一模一样的图片重新 mint，市场也会把它视为“仿品”，因为合约地址和历史不同。这种“真实性”与“稀缺性”来自合约中设定的最大供应量（例如 10,000 个），即便原作者重新部署一个新合约，市场通常也不会承认它的价值。

同时也明确指出，NFT 世界是一个\*\*完全无许可（permissionless）\*\*的环境，任何人都可以部署合约、发行 NFT，因此垃圾项目和投机行为不可避免。用户需要自己判断，而不是默认“下一个蓝筹”。在 OpenSea 中还能看到 NFT 的属性（traits）和稀有度比例，这些属性数据通常存储在 metadata 中，构成 NFT 价值的一部分。

NFT 不只是艺术品，也可能具有 **utility（功能性）**。课程举了几个例子，比如 token-gating（只有持有 NFT 才能进入某个 Discord 或聊天室）、治理投票（持有 NFT 才有投票权）、链上游戏资产（马、鸡、道具等）。这些 NFT 本质上是“钥匙”或“权限凭证”，而不仅是收藏品。不同 NFT 所在的链也可能不同，例如以太坊主网或 Polygon（L2），这引出了对 Layer 2 的简单提示，但当天主要仍聚焦在以太坊主网。

接下来课程选择了一个具体项目，演示 **在项目官网直接 mint NFT**，而不是在二级市场购买。通过连接 MetaMask，用户向一个智能合约发送交易，支付 mint 费用和 gas。这里重点强调了一点：在 Web3 中，用户是在“向合约打钱”，而合约代码是公开的。通过 Etherscan 可以查看合约地址、交易记录，甚至直接阅读 Solidity 源码。虽然普通用户不会逐行审计代码，但理解“你在信任一段公开代码”是非常重要的 Web3 认知。

NFT mint 成功后，虽然是在项目官网铸造的，但因为遵循 ERC-721 标准，它会自动出现在 OpenSea、Zapper 等其他平台中，再次印证了“资产与身份跨平台流动”的概念。不过课程也展示了现实中的不完美：不同平台对 NFT 的 **索引和展示是有选择性的**。有些市场（如 Foundation、Rarible）是高度策展和中心化的，它们可能不显示你合法拥有的 NFT，或者不解析 ENS。这引出了一个重要讨论：**Web3 的协议层是去中心化的，但很多应用层仍然是 Web2 公司，存在展示层面的“软审查”**。Web2 与 Web3 并不是非此即彼，而是混合存在。

随后课程深入到 NFT 的底层结构，对比了 **on-chain NFT** 和 **IPFS NFT**。大多数 NFT 实际上并不是把图片直接存到链上，而是：

-   链上合约只负责记录“谁拥有哪个 token ID”
    
-   token ID 对应一个 tokenURI
    
-   tokenURI 指向 IPFS 上的 metadata（JSON）
    
-   metadata 再指向图片、SVG 或其他资源
    

通过 Etherscan 的 readContract 功能，课程一步步演示了如何查询 tokenURI，再通过 IPFS 网关查看 metadata 和图片。这里引出了 IPFS 的核心概念：**内容寻址（content-addressed）**。在 IPFS 中，地址是内容的 hash，只要内容发生任何变化，hash 就会完全不同。这意味着：只要地址不变，内容就是不可篡改的；如果内容变了，它就“不是同一个东西”了。

这也带来了对 NFT 风险的讨论。如果 metadata 或图片只是指向某个普通 Web 服务器，创作者是可以随时替换内容的，NFT 的“不可变性”就被破坏了，这也是常见的 rug 风险之一。相比之下，把内容放在 IPFS（并确保被 pin）或直接 on-chain，会更接近 NFT 的精神。

课程还通过 Loot 和 SVG NFT 的例子，说明 **on-chain NFT 的可组合性（composability）**。当属性、颜色、形态都直接存储在合约中时，其他合约就可以读取并基于这些属性进行二次创作，例如繁殖、升级、游戏交互等。这种“无需许可的组合”是 Web3 非常独特的能力。

在技术层面，课程最后用一个极简的 Solidity 对比解释了 **Fungible Token（ERC-20）** 和 **Non-Fungible Token（ERC-721）** 的本质区别。ERC-20 是通过“地址 → 余额”的映射来表示价值，转账只是数字的加减；ERC-721 则是通过“token ID → owner”的映射来表示所有权，每一个 token 都是独一无二的。所谓“发送 NFT”，并不是物理传输，而是全网共同更新一份“谁拥有它”的账本状态。

最后回到一个重要的认知转变：区块链不是“资产在网络中移动”，而是**所有节点同时更新一份状态账本**。你签名一笔交易，网络确认后，所有人都同意“所有权发生了变化”。理解这一点，是从 Web2 思维转向 Web3 思维的关键一步。

这一天的核心并不是“买了什么 NFT”，而是通过完整链路理解：NFT 是如何被铸造的、如何在不同平台被识别、它真正“存在哪”、你究竟拥有什么，以及哪些地方仍然存在 Web2 式的中心化与风险。

**How to set up a wallet and become a power user on Ethereum**。这一节的核心目标不是写代码，而是**把钱包真正用起来**：理解 wallet 是什么、seed phrase 是什么、安全模型是怎样的，以及如何开始像一个“power user”一样使用 Ethereum。

课程从 **MetaMask** 开始。MetaMask 被明确介绍为 _go‑to browser extension_，但也提前给了一个重要的免责声明：**MetaMask 是 security‑first，而不是 UX‑first**。这意味着 Web3 世界里很多操作会显得“clunky”，但这些复杂性大多是为了安全服务的。安装时一定要确认官网是 [metamask.io](http://metamask.io)，防止 phishing（如 fake 域名 mediamask 之类）。

创建钱包时最关键的概念是 **12‑word seed phrase / mnemonic / secret recovery phrase**。它被反复强调为 **master key**：这 12 个单词按顺序决定了你整个钱包的控制权。任何人一旦拿到这 12 个词，就可以在任何地方 **recreate your entire wallet** 并立即清空资产。与之相对的是 MetaMask 设置的 **local password**，它只是用来在本地设备上加密钱包数据，如果忘了可以通过 seed phrase 恢复，所以它的安全等级远低于 seed phrase。关于 seed phrase 的保存方式，课程强调的不是“最聪明”，而是“**能恢复 + 足够安全**”。常见错误包括：截图、通过 WhatsApp/Telegram 发送、复制到明文文档、随便存在 GitHub 或文本框里。相对可接受的方法包括：手写在纸上、放在 password manager（如 1Password），但前提是资产规模不大。如果是高价值资产，就需要更高级的方案，比如 **hardware wallet + multisig smart contract wallet**。同时也提醒：不要过度“创意型安全”，比如把 seed phrase 拆得太复杂，最后连自己都无法恢复。

一个非常重要但常被忽视的实践是：**在往钱包里打真实资产之前，先验证你能不能恢复它**。例如删除 MetaMask → 用 seed phrase 重新导入 → 确认地址一致。这一步如果失败，说明你的备份方案本身是有问题的。

在确认 seed phrase 时，MetaMask 要求用户重新按顺序排列 12 个单词。这里顺带引出了一个安全问题：**为什么不能暴力枚举 12 个单词？** 理论上是可能的，但实际组合空间巨大（类似 52 张牌洗牌的例子），即使全世界一起跑脚本，也几乎不可能撞到一个已有余额的钱包。这是密码学安全的基础假设之一。

钱包创建完成后，课程强调了一个 Ethereum 非常反直觉但核心的特性：**创建账户不需要任何许可**。你不是被“注册”进某个数据库，而只是生成了一个足够随机的数（seed phrase → private key → address）。任何人都可以创建账户，这也是 Ethereum 的 permissionless 特性。接下来进入实操：发送 ETH，但首先是在 **testnets** 上完成。课程介绍了 testnet 的作用：它们是“真实运行的 Ethereum 网络”，但 ETH 没有真实价值，主要用于开发和学习。提到的 testnets 包括 **Ropsten、Kovan、Rinkeby、Goerli**，并简单区分了它们的特点（block time、使用场景、未来可持续性）。获取 testnet ETH 的方式是通过 **faucet**。在转账过程中，强调了几个 power user 的基本习惯：发送前要反复核对地址（开头几个字符 + 结尾几个字符），理解 **gas fee** 是发送交易必须支付的成本，并意识到“你需要花 ETH 才能转 ETH”。之后引入了 **Etherscan** 作为 _disinterested third party_ 和 **block explorer**。Etherscan 被定义为 Ethereum 的公共基础设施，用来验证“交易是否真的发生了”。通过 transaction hash，可以看到 from / to、value、gas、block、data 字段；也可以通过 address 页面查看所有交易历史，包括 **internal transactions**（例如 faucet 通过 smart contract 发币）。一个非常重要的 Web3 现实是：**交易不可逆，没有客服**。一旦交易被 mined，就无法撤回。唯一接近“撤销”的情况发生在交易还停留在 **mempool** 时，可以通过发送一个 **same nonce + higher gas** 的交易来 replace / speed up / cancel。但一旦上链，结局不可改变。这一节最后明确了学习成果：到此为止，你已经完成了在 Ethereum 上的“第一步”——你创建了 wallet，理解了 seed phrase 的安全模型，能在 testnet 上发送 ETH，并会用 Etherscan 验证链上行为。接下来要深入的是：**seed phrase 如何派生 private key / public address、ECDSA key pairs、以及一个 seed phrase 如何生成多个 accounts**——这些将是从“会用”走向“真正理解”的关键。

### NFTs!!! ERC20 vs ERC721, IPFS, Metadata

**“NFT Day” 的实操与原理结合课程**，目标是让初学者：

-   亲手 **买 / mint / 查看 / 转移 NFT**
    
-   理解 **NFT 在技术上到底是什么**
    
-   看清 **Web3 的理想 vs 现实（去中心化 vs 平台化）**
    

## **二、NFT 核心概念**

### **1\. NFT 是“所有权记录”，不是图片本身**

-   区块链只负责记录：\*\*谁拥有哪个 token｜\*\*真正的内容（图片 / 元数据）通常：
    
-   要么 **存在 IPFS**
    
-   要么 **直接写在智能合约里（on-chain SVG）**
    

👉 真正“拥有”的是：**一个指向内容的不可篡改凭证（receipt）**

### **2\. ENS、本身就是 NFT**

### ENS 域名是 ERC-721 NFT

-   谁持有这个 NFT，谁就控制这个名字
    
-   把 ENS 转走 = 把控制权转走
    

### **3\. NFT 的价值来自三件事**

1.  **出处 / provenance**（谁 mint 的、历史如何）
    
2.  **稀缺性**（合约里写死的 total supply）
    
3.  **社区与共识**（市场是否承认这是“正品”）
    

👉 就算复制一模一样的图片，只要不是原合约 mint，**市场不会认**

## **三、NFT 的几种形态（很重要）**

### **1️⃣ Marketplace 买的 NFT（如 OpenSea）**

-   二级市场
    
-   平台展示 ≠ 链上真实存在
    
-   平台有 **强 Web2 式的筛选 / 审查**
    

### **2️⃣ Mint 网站直接 mint**

-   直接与智能合约交互
    
-   风险更高（要“信任代码”）
    
-   更贴近 Web3 本质
    

### **3️⃣ On-chain NFT（高级玩法）**

-   SVG / metadata 直接写在合约里极贵，但：
    
-   **完全不可篡改**
    
-   高度可组合（适合游戏、机制设计）
    
-   **4️⃣ IPFS NFT（最常见）**
    
-   合约只存 token → URI
    
-   URI 指向 IPFS 上的 metadata
    
-   Metadata 再指向 image
    

## **四、IPFS 的关键思想**

### **Content-addressable（内容寻址）**

-   文件的 **hash = 地址**
    
-   内容改 1 个字节 → 地址就变
    

所以：

-   ✅ 不可篡改
    
-   ✅ 没有“假副本“
    

⚠️ 但现实问题：

-   如果没人 pin，内容可能消失
    
-   需要 Pinata / Arweave 等服务
    

## **五、Web3 的“理想 vs 现实”**

### **理想：**

-   NFT 遵循标准 → 应该在哪都能看到 / 交易
    
-   去中心化、抗审查
    

### **现实：**

-   OpenSea / Rarible / Foundation 都是 **Web2 公司**
    

**Web2 和 Web3 并不是非此即彼，而是强烈混合**

## **六、Fungible vs Non-fungible（技术本质）**

### **Fungible（ERC-20）**

-   记录的是：**地址 → 余额**
    
-   转账 = 数值加减
    

### **Non-fungible（ERC-721）**

-   记录的是：**tokenID → owner**
    
-   每个 token 独一无二
    
-   转移 = 改 owner
    

👉 NFT ≠ “在网上传文件”

👉 NFT = **全网同步更新的一本“所有权账本”**

## **七、艺术家 & 创作者的意义**

NFT 让艺术家可以：

-   直接面对支持者（而不是平台）
    
-   写入 **版税（royalties）**
    

用 NFT 做：

-   门票
    
-   投票权
    
-   社群准入
    
-   游戏资产
    

👉 从「百万粉丝」转向「百个超级支持者」

## **八、重要风险提示**

-   不看 tokenURI = 不知道你买了什么
    
-   NFT 指向个人服务器 = **可被随意替换（rug）**
    
-   未验证合约 = **极大风险**
    
-   发错地址 / 发到合约地址 = **永远找不回**
    

NFT 可以被理解为一种**策展机制而不仅是媒介**：它通过区块链把“所有权、出处与规则”写入一个不可篡改的系统，使作品不再只依赖展墙、平台或机构来获得合法性。在策展层面，这意味着策展人不只是选择作品本身，而是在设计**作品如何被生成、流通、被观看与被记忆的条件**——从智能合约、内容存储方式（on-chain / IPFS），到平台是否展示、社区是否承认，都是策展的一部分。NFT 展览因此更像是在组织一套关于价值、信任与公共性的实验场，而不是简单地把数字图像搬进展厅
