# **什么是以太坊2.0**

**共识机制升级：以太坊2.0将把以前依靠高耗能的PoW工作量证明改为PoS。在PoS中，用户通过质押（staking）自己的ETH来参与网络的共识，成为验证者，从而获得奖励。这种方式不仅能大幅降低能源消耗（可减少99.95%的能耗），还能提高网络扩展性和交易处理速度。**

**多阶段升级：以太坊2.0的升级分为几个阶段，主要包括信标链（Beacon Chain）的上线、主网与信标链的合并（The Merge）以及未来可能的分片链（Shard Chain）来进一步提升网络吞吐量。**

**​所以如果想要在以太坊2.0上进行质押需要满足一定条件，而Lido则可以帮助我们解决这些条件。针比如对第三个问题**

**因为如果将eth存入新标链中是无法提取出来的。而Lido创建了一种锚定资产，就是stETH，将我们的eth在lido中去stake，就可以获得stETH。stETH就是一种代表你在Lido中质押的ETH的衍生凭证。并且是具有流动性的。stETH代币会随着质押奖励的累积而自动增值。**

**等以太坊2.0上线后，可启用提现功能，允许用户将stETH兑换回原始的ETH和累计的质押奖励**。

# 区块链数据结构

## 链上数据基本类型

交易数据：包含交易的数据，如转账金，收发地址，手续费等。帮助追踪链上转账资金流动，了解交易方，钱包地址

## 区块数据

区块自身信息数据，如时间戳（区块生成的时间），验证者，交易排序

## 合约数据

链上部署的智能合约代码。

开发者预先写好的代码，无法更改

## 链上交易

链上交易是区块链状态改变的主要方式，每笔交易的基本生命周期包括创建，广播，打包，确认

-   交易创建
    
-   交易广播
    
-   交易确认
    

# 常见数据指标

交易哈希：相当于交易的身份证，通过交易哈希可查询该交易的所有信息

交易状态：交易成功/失败。

value：转账的费用

-   区块
    
    -   是区块链的基本组成单位
        
    -   区块结构
        
        -   区块头：提供交易元信息链接其他区块
            
        -   区块体：交易数据或其他记录
            
    -   生成过程
        
    -   区块作用
        

智能合约数据：合约地址，合约定义逻辑（函数），合约定义事件，合约定义变脸

## 常见数据指标

总锁仓量TVL：生态中被锁定的加密资产的总价值，包括流动性池，抵押贷款，和收益聚合中的总资产价值。这个指标反应了defi市场协议的比重。  

活跃地址数：在一段时间内至少执行一次交易的钱包地址数量（相当于日活跃，月活跃）。活跃地址数量可以反应区块链及应用的用户基础及增长趋势，

交易量：一段时间内链上发生所有交易的数量，交易量是这些交易涉及资产价值的总额。交易量反应了交易的资产规模。也可评估区块链网络健康，交易活动以及市场情绪的重要指标。  
交易数：特定时间短内所有交易哈希数

交易费用/gas费用：用户在交易的成本。反应了区块链网络的拥堵程度和交易成本。交易费：交易使用的gas数量\*gas价格

高交易通常表示网络较为拥堵，用户交易成本高

以太坊gas价格追踪：https://etherscan.io/gastracker

协议收入:服务收取一定比例的费用。衡量一个协议业务的盈利能力，并能够为代币持有者带来的价值

协议费用=用户为使用平台或服务而支付的总价值

# **plume质押与流动性项目**

## Nest

Nest 是 Plume 网络中的旗舰质押协议，专注于将现实世界资产（RWA）与 DeFi 融合，为用户提供机构级收益。下面详细解析 Nest 项目的核心内容、其合作优势及潜在投资价值：

**功能定位**：

Nest 作为 Plume 上的质押协议，允许基金经理和资产发行方在无需许可的环境下创建结构化产品。通过这种方式，传统上难以直接进入的高质量资产（如代币化证券、私募信贷等）得以在链上公开交易，并为普通投资者

**技术**：利用plume的基础设施，集成智能钱包）和模块化工具。不仅支持常规的质押和借贷，还能实现复杂的收益分配和流动性管理，为用户提供更高的资产利用效率。

### 与plume合作优势：

随着 Plume 与多家机构（如 Whinfell、Plural 等）的合作，Nest 也逐步推出了机构级核心 Vault。这一功能使机构投资者可以使用平台上的稳定币（如 deUSD、sdeUSD）参与收益获取，降低了参与门槛，同时确保交易过程符合法规要求。

分析:

生态红利：Plume 网络目前已吸引超过 180 个项目构建生态系统，Nest 作为其中的关键节点，有望受益于平台整体的扩张和市场认可。

市场需求增长：全球对清洁能源、碳中和和其他 RWA 资产的关注不断上升，政策红利和市场需求为 Nest 的发展提供了有利条件。

高效的流动性管理机制：Nest 设有自动检测流动性不足时的处理机制，及时将基础代币转换为稳定币。这确保了即使在市场波动或赎回高峰期，用户也能顺利取回资金。

### 协议流程 ：

存款： 用户将稳定币存入 Nest 金库，并获得Nest金库代币作为回报。这些代币代表用户在金库中的份额，并随着金库持有增值基础代币而增值。

收益产生：金库会利用存入的稳定币购买基础代币，这些代币来自于收益发行方。收益发行方会将这些稳定币贷出给借款人，并收取利息。借款人归还本金和利息后，基础代币的价值会逐步上升。

提取： 当用户希望取回资金时，需要销毁（Burn）其持有的金库代币。如果金库流动性充足，则可以直接从储备中提取稳定币；如果流动性不足，金库会先将部分基础代币与收益发行方交换成稳定币，再将稳定币返还给用户。这种赎回机制保证了用户可以随时退出并取回资金，同时通过自动交换基础代币确保金库始终保持足够的稳定币储备。

## 加密哈希函数

-   可以将任何字符串作为输入，产生固定长度输出
    
-   三个属性
    
    -   collision-free碰撞自由性：即不存在 两个不同的输入会产生相同的输出。（无碰撞）
        
        -   意味着没人可以找到x和y
            
        -   x和y是不同的，但是x和y的哈希值是相同的（ H(x) =H(y) )
            
        -   解释：因为当两个不通过的输入产生相同的输出时，说明碰撞是存在的，而加密哈希函数需要“没人能发现碰撞“（因为事实上碰撞是存在的），所以具有collision-free
            
            -   碰撞为什么一定存在
                
                -   因为我们有很多可能性的输入，但是输出确实固定长度的，意味着输入大于输出的量，所以存在两个不同的输入可能产生相同的输出
                    
        -   Q：如何找到碰撞
            
            -   随机选择130个输入，就会发现至少有两个它们之间会发生碰撞的概率有99.8%
                
                -   这必须算出130个数的哈希值，然后找出每两个之间相同的概率（很麻烦）
                    
        -   因为没有人证明出哪个加密哈希函数不存在碰撞，所以我们假定我们有一个无碰撞（冲突）的哈希函数。那无碰撞（冲突）有什么意义呢？
            
            -   假设我们记住一个文件的哈希，之后又有一个新文件，我们需比较这两个文件哈希是否一致，一致的话，我们得出结论，这两个文件是相同的（因为我们的哈希函数是无碰撞的，意味着这两个文件x和y不能是不同的）。这有利于我们知道旧文件的摘要
                
    -   hiding隐藏性：即使知道输出，也无法推算出输入x。
        
        -   为了让别人很难通过h（x）找到输入值x，我们必须引入隐形值r，r是从具有高最小熵的分布中选择的随机值（即r是从真正分散的发行版中选择的，则r没有特定的值）。则把x和r串联起来将h（x)变为 h(r| x)则意味着取出r的所有数加上x所有数。这样就很难找到x了
            
        -   应用
            
            -   承诺

# 概述

区块链是一种分布式账本技术，通过加密链式结构和共识机制，实现去中心化、数据不可篡改和高度透明的记录存储。它不仅支撑数字货币，还广泛应用于供应链、金融、医疗、政务等领域，并正随着智能合约与 Layer 2 方案的发展进入新阶段。以下章节将详细阐述区块链的各方面内容。

# 基本概念

定义：区块链是一种分布式数字账本，记录所有网络参与者之间的交易或状态变更，各节点共享同一账本副本，具有防篡改和可追溯特性​

特征总结：它融合了分布式存储、加密算法、共识协议和点对点网络，构成一个无需信任第三方的可信系统。

# 核心特性

去中心化：数据不依赖单一服务器或机构，而是在所有节点间同步，消除单点故障与托管风险。

不可篡改：每个区块包含上一区块的哈希值，一旦写入就难以篡改，保证历史记录的完整性和可审计性​。

透明性与可追溯性：链上交易对所有参与者可见，任何修改都会留有痕迹，便于审计和监管。

# 架构组成

区块（Block）：包含若干已验证的交易数据、时间戳、前一区块哈希等内容，构成账本的基本单位。

在区块中我们把数据分成了块高，Nonce，Data，需将这三个进行哈希运算得到哈希值。当我们提供了这三个值放入哈希函数再”Mine”后会得到一个哈希值：此时的Nonce值就会改变。早起矿工挖矿就是解决这个问题：矿工需找到一个Nonce，这个Nonce需和块高和Data一起进行哈希运算，结果必须是以4个0开头的哈希值。

节点（Node）：运行区块链软件的计算机，存储账本副本并参与交易验证，分为全节点和轻节点两类。

点对点网络（P2P）：节点之间通过对等网络协议广播交易和区块，实现信息传播与同步​。

智能合约（Smart Contract）：部署在链上的自动执行代码，用于实现去中心化的业务逻辑和资产管理。

\## 共识机制

Proof‑of‑Stake（PoS）：节点通过抵押代币获得打包权，降低能耗并提高吞吐，已被以太坊等主流网络采用。

在权益证明系统中，区块是“锻造”而非“挖矿”而来。参与锻造过程的用户必须将一定数量的代币锁定到网络中，作为他们的权益而存在。权益的大小决定了选择一个节点作为下一个验证者的机会，权益越大，机会越大。为确保该过程不仅仅偏向网络中最富有的节点，这个选择过程添加了很多特殊的方式。最常用的两种方法是“\_随机区块选择\_(Randomized Block Selection)”和“\_币龄选择\_(Coin Age Selection)”。

其他机制：包括Delegated PoS、Practical Byzantine Fault Tolerance (PBFT)、Hashgraph 等，适用于不同信任与性能需求。

\##### DAO\*\*（去中心化自治组织）\*\*

**DAO（Decentralized Autonomous Organization，去中心化自治组织）** 是基于智能合约运行的组织，管理权力由代币持有者投票决定，而不是由传统的公司管理层控制。

\- **去中心化**：所有决策由社区成员投票决定，而非中心化机构。

3\. **投票机制**：多数 DAO 采用链上投票（如 Snapshot、Tally）决定提案是否通过。
